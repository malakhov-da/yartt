# Contributing

Ideas, questions and bug reports are welcome as issues.

Code is welcome too, on one condition: yartt has a single owner of the
copyright, Dmitriy Malakhov. This keeps the project free to grant
commercial licenses (see [LICENSE.md](LICENSE.md)) and to pass on as a
whole. So before a pull request is merged, its author transfers the
copyright in it by signing an assignment agreement:

- [Individual agreement](legal/CAA-individual.md) — you write the code
  yourself and it belongs to you;
- [Entity agreement](legal/CAA-entity.md) — the code belongs to a company,
  for example your employer; the company signs it.

You keep a broad license to your own contribution (section 2.1(d)) and
remain its author. A pull request whose author has not signed is not
merged.

## How to sign

On your first pull request a bot (CLA Assistant) posts a comment with a
link to the agreement. Sign it there once; it covers all your later
contributions. A company signs the entity agreement by sending a signed
copy instead.

## Code you did not write

Do not include code you do not own, even a snippet, unless it comes under a
license compatible with yartt (MIT, BSD, Apache 2.0, ISC). Mark such code in
the pull request: name its source and its license and keep its copyright
notice. Its copyright stays with its authors.

If you write code as part of your job, your employer most likely owns it:
ask them to sign the entity agreement first.
